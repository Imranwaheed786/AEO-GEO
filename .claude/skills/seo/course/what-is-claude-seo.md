# What is Claude SEO
Claude SEO is a skill that turns Claude Code into a full SEO analysis engine. One install gives you 13 sub-skills, 7 parallel subagents, and a scoring framework that produces actionable audit reports, all running locally inside your terminal. 
Instead of juggling Ahrefs, SEMrush, Screaming Frog, and a dozen browser tabs, you type one command and get a professional-grade audit in minutes.
Command & Purposes:
/seo audit <url>	Full site audit with 7 parallel subagents
/seo page <url>	Deep single-page analysis with 5 score cards
/seo technical <url>	9-category technical SEO breakdown
/seo geo <url>	AI search optimization analysis (GEO)
/seo schema <url>	Detect, validate, and generate structured data
/seo plan <type>	Industry-specific strategic SEO plan
Claude SEO is fully open source with 2,300+ stars and 374 forks. You can explore the full codebase, report issues, contribute, or fork it for your own customizations:
