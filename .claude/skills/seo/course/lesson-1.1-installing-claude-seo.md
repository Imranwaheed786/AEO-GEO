# 1.1 Installing Claude SEO
Get Claude SEO running in under two minutes. One command installs 13 sub-skills, 7 subagents, and all reference files into your Claude Code CLI.
The Command
macOS / Linux:
curl -fsSL https://raw.githubusercontent.com/AgriciDaniel/claude-seo/main/install.sh | bash
Windows:
git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
powershell -ExecutionPolicy Bypass -File claude-seo\install.ps1
You can also just copy the github link, paste it in a claude chat and prompt "Install this" 
Verify It Worked
Open Claude Code and type /seo. You should see the full list of available commands. If you do, you're set.
