# Outrank Everyone, Lesson 2: Install skills
In Lesson 1, you installed Claude Code. That was the engine. Now you're installing the GPS. Skills are what turn a general-purpose AI into a specialized marketing machine that knows exactly what to do when you type a slash command.
Two repos. Two git clone commands. Five minutes. Let's go.
What Are Claude Skills?
Skills are GitHub repos that teach Claude specialized workflows. You clone them, Claude reads the instructions inside, and you get slash commands that produce professional-grade marketing output.
That's it. No plugins to configure. No extensions to install. Clone a repo, cd into it, run claude, and the skills are live.
How it works under the hood: Each skill repo contains a CLAUDE.md file with detailed instructions. When you run claude inside that directory, it reads the file and unlocks all the slash commands. Simple. Elegant. No magic.
