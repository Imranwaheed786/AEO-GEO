# 1.3 Reading Audit Reports
Your audit produced two files. This lesson teaches you how to read them, spot patterns, and translate technical jargon into plain English.
Executive Summary Section
Start here. Every audit report opens with three things:
Health Score - Your overall number out of 100
Top Issues - The biggest problems dragging your score down
Quick Wins - Easy fixes with high impact
Spot the Pattern
Before fixing individual issues, look for patterns. Template-level problems appear on every page (broken schema, missing meta tags). Page-specific issues only affect one URL. Fix template problems first. One fix, every page improves.
Practical Tips
Read the ACTION-PLAN.md first. It tells you what to fix and in what order.
Check if a finding is template-level or page-specific before diving in.
Critical items often block other improvements. Start there.
If you want a pdf report, feed this prompt: 
Great work on the audit. Now please generate a professional PDF report with the following requirements:
Content:
Include all audit findings, data points, and recommendations
Embed relevant screenshots inline with their corresponding sections
Add charts/graphs to visualize key metrics and trends
Formatting & Layout:
Use a clean, professional layout with a title page, table of contents, and section headers
Ensure no overlapping elements — text, images, and charts should be properly spaced with clear margins
Use consistent fonts, colors, and styling throughout
Add page numbers and section dividers
Visuals:
Use bar/pie/line charts where data comparisons are relevant
Size all screenshots and visuals to fit within page boundaries
Include captions and labels for every visual element
Output:
Save as a single, well-formatted PDF with no layout issues
Review the final output for any clipping, overflow, or overlap before saving
