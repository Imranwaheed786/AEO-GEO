# 1.4 Single Page Deep Dive
The full audit shows your site. The page command zooms into one URL and gives you five detailed score cards to work with.
The Command
/seo page https://yoursite.com/target-page
Five Score Cards
When to Use Page vs Audit
The Optimization Loop
This is the workflow you will repeat throughout the course:
Audit the site - Find weak areas with /seo audit
Identify weak pages - Check which URLs drag scores down
Deep-dive each page - Run /seo page for detailed analysis
Fix the issues - Work through findings by priority
Re-run and verify - Confirm scores improved
Practical Tips
Run /seo page on your homepage and your top landing page. Compare the results.
After making fixes, re-run the same command to confirm the score went up.
Focus on the lowest score card first. That is where you get the biggest gains.
